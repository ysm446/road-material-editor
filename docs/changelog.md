## 未リリース

### 2026-09-07 19:14 — 道路の材質変化と沿道接続

新舗装・荒れた舗装・砂利道など、道路の材質が進行方向に変わる状態で左右の沿道を接続可能にした。道路最大3種類（各4層）、左右各2種類（下地1層）まで。

### 2026-09-07 19:04 — 左右同時の沿道接続

道路と左右の路肩・歩道を同時に馴染ませられるようにした。左右それぞれの切替位置と素材を保ち、道路の両端で変位を抑える。「配置する側」は編集する沿道だけを選ぶ。

### 2026-09-07 18:52 — 右沿道の横接続

右側の路肩・歩道にも材質と変位を接続できるようにした。両側に沿道がある場合は「配置する側」で接続する片側を選べる。

### 2026-09-07 18:46 — 曲線・坂道の沿道生成

道路距離の丸め誤差で「沿道の面が縮退しています」と表示され、沿道が消える場合がある問題を修正した。

### 2026-09-07 18:40 — 横接続時のハイト変位

左沿道の横接続に「変位もつなぐ」を追加。境界付近の凹凸を滑らかに抑え、歩道の基準段差を保って接続する。沿道の凹凸の高さを編集可能にし、白線の変位参照座標も道路へ揃えた。

### 2026-09-07 18:27 — 左沿道との横方向の材質接続

道路と左路肩の材質境界を両側で共通に評価する試作を追加。「横接続を試す」で有効化し、歩道の輪郭は保持する。道路1種類＋左沿道最大2種類、接続中の変位は停止。検証用Releaseは `road_editor_connections.exe`。

### 2026-09-07 18:16 — 沿道の下地材質と区間混合

沿道の下地材質を区間の形状と同じ割合で混合する。素材・反復長・座標、素材なしの場合の色・粗さを編集可能。下地1層・最大3プリセット、ハイト変位と上層合成は後続。法線マップの前後方向も修正。

### 2026-09-07 18:04 — 沿道断面の生成と仮配置

Roadに「沿道形状（試作）」を追加。左右に仮の路肩から歩道へ移る2区間を作り、境界と移行距離を編集できる。外部メッシュ素材は不要。単色の形状確認段階で、材質と変位の接続は後続。

### 2026-09-07 17:53 — Roadの旧材質入力の表示整理

区間プリセットを使うRoadの旧Material／Mask入力と接続線を通常は非表示にした。「旧入力を表示」で再表示でき、元の接続は保持する。

### 2026-09-07 17:45 — プリセットの材質・マスク詳細を編集

- Roadの区間プリセットで座標、層の混ぜ方、高さ条件、ブレンド幅とPBR定数を編集できる。
- 轍の幅、道路端の左右と範囲、ノイズの大きさ、ムラ・シード・反転を追加。Road Maskノードと共通の編集処理を使用する。
- 保存形式は版18のまま。既存の保存・Undo経路へ反映する。

### 2026-09-07 17:28 — 路面区間を画面上で編集

- Roadに「路面区間」を追加。現在の材質から始め、分割・距離変更・プリセットの複製と割当・素材の変更ができる。
- 通常起動の描画へ反映し、白線は元の色で路面の変位へ追従する。保存・Undo対応。
- [試用手順](reference/road-surface-editor.md)。沿道の自動接続と公開値の結線は後続。


### 2026-09-07 16:51 — 多層プリセットの保存と評価

- 道路区間プレビューでプリセットごとに最大4層を合成。層のマスク・UV・高さ条件を維持する。
- 保存形式を版18へ更新し、版17の単層記述も読み込める。多層設定はUndo対象。


### 2026-09-07 16:41 — 道路区間の材質プレビュー

### 2026-09-07 15:54 — 接続試作のGPU計測

- `--measure-preview` でGPU描画時間・VRAM・CPU生成時間をログへ出す。
- 接続辺をGPUで両側から評価し、0.1 mmの許容差と1 mmの確認値を検査する。範囲はサンプル点に限定し、全視点での亀裂保証とは分ける。
- 検証コピー生成に `--length` を追加。50 mの通常道路と9層の接続試作を比較した。詳細は [計測資料](reference/connection-diagnostics.md)。

### 2026-09-07 15:13 — 道路・沿道の自動接続試作

- 接続試作が道路・路肩の4層ずつの材質構成と仮歩道を扱えるようになった。元のマスク・UV・高さ条件・変位量を保持して接続する。検証用コピー生成に `--layered` を追加。
- 開発用の --connection-prototype を追加。一本の直線道路で舗装から砂利への移行、砂利路肩との接続、15 cmの仮歩道を確認できる。
- 仮歩道は素材画像を使わず、目地を実際にくぼませたコンクリート平板のメッシュとして作る。
- 既存プロジェクトの素材から検証用コピーを作る tools/make_connection_prototype.py を追加。通常のグラフ評価・保存は従来どおり。
- 使い方と未対応範囲は [接続試作](reference/connection-prototype.md) を参照。

- 描画結果は変わらない（レイヤー付きの道路で変更前後の画像を比較して一致）。

### 2026-09-07 12:30 — 旧地形の仕様を UI から外す（第一段）

- ノード追加メニューを Road / Lane Marking / Road Mask / Decal / Shoulder / Merge / Crack / Mesh Output / Path / Surface だけにした。Heightmap・Shape・Liquid・侵食系・Mask 系・Output は出さない（旧ファイルの読込は残る）。

- Surface などの Base 入力ピンは、繋がっていないときは出さない（Mask と同じ）。

### 2026-09-07 12:00 — 混ぜ方「マスクどおり」と、旧マスク入力の整理

- Road / Shoulder の材質スロット 2〜4 に「混ぜ方」を追加。既定の「マスクどおり」は Road Mask の被覆率がそのまま重みになり、マスクを塗った所にその材質が出る（境界だけ下地とのハイト差で崩す）。従来の「ハイトで競合」も選べる。既存のファイルは「ハイトで競合」のまま読む。
- Surface などのレイヤーノードの Mask 入力（旧地形の合成用）は、繋がっていないときはピンを出さない。プロパティのマスク節も設定済みのときだけ出す。道路の配置は Road Mask だけで決める。

### 2026-09-07 11:30 — 材質スロットを下地のハイトで絞る

- Road / Shoulder の材質スロット 2〜4 に「下地のハイト」（使わない / 下地の高い所 / 下地の低い所）としきい値・柔らかさを追加。Road Mask の被覆率に、下地の凹凸から作った 0〜1 を掛ける。砂利の粒の間に土が溜まる、といった起伏に沿った配置ができる。変位も同じ計算に従う。

### 2026-09-07 11:00 — Road Mask にワールドノイズ

- Road Mask の形に「ワールドノイズ」を追加。ワールド XZ で評価する方向性の無いノイズで、左右の路肩や隣の道路と模様が連続する。路肩の砂利や土の分布向け。

### 2026-09-07 10:40 — 材質の「明度」

- マテリアルに「明度」を追加（並びは 明度・彩度・色相）。ベースカラーに掛ける倍率で、色相・彩度の後に効き、1 を超えた成分は 1 で止める。暗すぎるスキャン素材を持ち上げる用。サムネイル・球・合成で同じ値を使う。

### 2026-09-07 10:00 — Crack ノード（ひび割れの自動配置）

- Crack ノードを追加。Road の RoadSurface を繋ぐと、3〜6 m の枝分かれしたひび割れの塊を乱数で道路に置く。密度・乱数種・長さ・向き（縦 / 横 / 混合）・横位置（一様 / 轍寄り / 端寄り）・幹の幅・枝の数と長さを設定できる。
- 帯は Decal と同じ仕組みで、枝は先端へ向かって細くなる。Material に割れ目の材質（マスク抜き）を繋ぐ。個別に置きたいものは面上の Path ＋ Decal で描く。
- 割れ目の見え方は材質のコントラスト次第。マスクの帯が細い素材では、割れ目の内側が路面より十分暗い（またはハイトで凹む）必要がある。
- プロジェクト形式を版16へ更新。

### 2026-09-07 09:30 — 路肩の段差

- Shoulder に「段差」と「面取り幅」を追加。段差を 0 より大きくすると、境界の直後に面取り列を挟んで路肩全体をその高さだけ下げる。境界の頂点は道路と共有したまま。

### 2026-09-07 09:10 — 停止線

- 実寸 Path の点に「停止線」（なし / 進行方向 / 対向 / 両方）を付けられるようにした。Road がその点に最も近い実距離を控え、Lane Marking がその向きの車線の幅いっぱいに帯を引く。
- Lane Marking に「停止線」のオン・オフと幅（既定 0.45 m）を追加。

### 2026-09-07 08:50 — 轍を車線に合わせる

- Road Mask の轍に「車線に合わせる」を追加。Road の車線数から各車線の中央に轍を置く。「両車線」は対向車線にも置くか。既存のファイルは手入力のまま読む。

### 2026-09-07 08:30 — 車線数と車線境界線（破線）

- Road に車線数（進行方向 1〜8、対向 0〜8）を追加。車線幅は全幅÷合計。対向 0 で一方通行。
- Lane Marking に車線境界線を追加。同方向の車線の間に破線（長さ・間隔、間隔 0 で実線）を引く。中央線は進行方向と対向の境に引き、矢印は各車線に置く。
- 保存はキー追加のみ（版15のまま）。

### 2026-09-07 08:00 — Shoulder の材質レイヤーと変位

- Shoulder に Road と同じ材質スロット（Material 1〜4、Mask 2〜4）、スロットごとの座標と反復長、ブレンド幅、変位量を追加。路肩も材質のハイトで押し出される。
- 路肩では Road Mask の「端の減衰」の 右＝境界側、左＝外側。既定の座標はワールド XZ。
- 保存はキー追加のみ（版15のまま）。

### 2026-09-07 07:40 — Road Mask の端の減衰に「側」を追加

- Road Mask の「端の減衰」で 両側 / 左 / 右 を選べるようにした。左右は Path の進行方向基準で、走行側には依存しない。Mask 3 を左の端、Mask 4 を右の端にすると、Road の端の層を左右で別の材質にできる。

### 2026-09-07 07:20 — Merge ノード

- Merge ノードを追加。Road・Shoulder・Decal などの RoadSurface を繋ぐと 1 つの RoadSurface にまとめ、Mesh Output 1 つで道路と路肩を同時に表示できる。入力は繋ぐたびに 1 本増える。
- 同じノード由来のメッシュは 1 回だけ積む（同じ Road を 2 つの枝から入れても道路面は二重にならない）。複数の Mesh Output にまたがる重複も除く。
- プロジェクト形式を版15へ更新。

### 2026-09-07 06:50 — Shoulder ノード（路肩の第一段）

- Shoulder ノードを追加。Path に Road の Left / Right か別の Shoulder の Outer を繋ぐと、境界の頂点を共有したまま外側へ幅と横断勾配で路肩を張る。出力は RoadSurface（Mesh Output へ）と Outer（次の路肩や Road へ）。
- 左右は Path の進行方向で決まり、走行側の設定には依存しない。
- プロジェクト形式を版14へ更新。

### 2026-09-07 06:10 — 道路メッシュの部分描画と途中経過の表示

- Road / Lane Marking / Decal の出力ピンをクリックすると、そのノードまでの道路メッシュをビューポートに出す。「Mesh Output へ戻す」か背景のダブルクリックで戻る。

### 2026-09-07 05:11 — 面上のパスと Decal ノード

- Path の入力を Surface（Mesh 型）に変更。Road の RoadSurface を繋ぐと面の座標で保持し、道路を変形しても追従する。路面の上で点を置き、路面に沿ってドラッグできる。
- Decal ノードを追加。面上の Path に沿って幅指定の帯を道路面と一体で貼り、材質の不透明度で模様をくり抜く。
- プロジェクト形式を版13へ更新。旧地形パスの Base への接続は読込時に外れる。

### 2026-09-07 04:42 — Surface ノードのサムネイル

- メッシュシーン表示中など合成結果が無いとき、Surface などのレイヤーノードに割り当てた材質のサムネイルを出す。

### 2026-09-07 04:34 — 道路の材質スロットと Road Mask

- Road に Material 2〜4 と Mask 2〜4 を追加。Road Mask ノード（轍 / 端の減衰 / 長さ方向ノイズ / 一様）で被覆率を決め、
  スロットの材質をハイトで競合させて混ぜる。変位もブレンド後のハイトで行う。
- スロットごとに「道路に沿う / ワールド XZ」の座標と UV 反復長を選べる。路肩や地面と地続きにする層はワールド XZ。
- プロジェクト形式を版12へ更新。

### 2026-09-07 02:59 — 白線の UV の向きと深度バイアス

- Road と Lane Marking に「UV の向き」を追加。横長の素材を道路や白線の長さ方向に沿わせられる。
- 白線の帯を深度バイアス付きで路面の後に描き、路面の分割との差で石が突き抜けて穴になる問題を直した。
- 材質に不透明度マップを付けたとき、合成が「不透明」のままなら自動で「マスク抜き」に切り替える。

### 2026-09-07 02:37 — 材質の不透明度と合成モード

- 材質に不透明度のマップと定数、合成モード（不透明 / マスク抜き / 半透明）、しきい値を追加した。
- 白線・矢印の帯は材質の合成モードに従い、剥げた塗料や薄く消えかけた塗料を表現できる。道路面は常に不透明。

### 2026-09-07 02:26 — 白線の路面追従

- 白線と矢印が道路面の変位に追従するようにした。頂点に道路 UV を持ち、路面と同じハイトで押し出す。

### 2026-09-07 02:17 — テセレーションの細かさ

- 「分割の上限」を 64 まで広げ、「分割する辺の長さ（px）」をプレビュー設定に追加した。近くは石の粒が形として出て、遠くは割らない。

### 2026-09-07 01:42 — 道路のテセレーションとワイヤーフレーム表示

- 道路メッシュにも平面と同じテセレーションを適用。プレビュー設定「道路」で有効化と分割の上限を設定する。
- Road ノードに「変位量」を追加。Material のハイトで路面を法線方向へ押し出す（既定 0）。
- 表示メニューに「ワイヤーフレーム（分割後）」を追加。シェーディングの上に分割後の辺を重ねる。

### 2026-09-07 01:29 — 走行側と進行方向の矢印
