## 未リリース

### 2026-09-07 01:29 — 走行側と進行方向の矢印

- プレビュー設定の「道路」に走行側（左側通行 / 右側通行）を追加。プロジェクトで 1 つ持ち、保存とアンドゥの対象。
- Lane Marking に進行方向の矢印を追加。左右の車線の中央に一定間隔で置き、走行側の車線は線形の向き、対向車線は逆向きにする。
- Road の Left / Right を進行方向に向かっての左右（右手系）に合わせた。以前は逆だった。バンク角の「正で Left 側上がり」もこの向きに従う。

### 2026-09-07 00:44 — 縦断曲線とバンク角

- 実寸 Path に縦断ポイント（縦断曲線長・オフセット）とバンクポイント（設計速度・自動/手動・角度）を置けるようにした。
- Road が縦断の放物線と、曲率半径と設計速度から求めた自動バンク角、手動バンク角を道路面・境界・白線へ反映する。
- プロパティの「道路線形」で編集モード・バンクの有効化・設計速度・摩擦係数・平滑化を設定する。
  ビューポートでは Ctrl＋クリックでポイントを置き、線に沿ってドラッグする。手動バンクは回転リングで角度を回す。
- プロジェクト形式を版11へ更新。

### 2026-09-07 00:20 — 白線ノード・表示メニュー・ライトギズモ

- Lane Markingノードを追加。RoadのRoadSurfaceを受け、中央線1本と左右の外側線を帯ポリゴンで生成し、道路とまとめてMesh Outputへ渡す。
- 線幅・端からの距離・浮かせ量・UV反復長を設定でき、Materialに塗料の材質を接続できる。UVは幅方向0〜1、長さ方向は実距離基準。
- プロジェクト形式を版10へ更新。旧アプリで白線ノードが読み飛ばされて道路が消えることを防ぐ。
- ビューポートの「表示 > ハイトの範囲」を撤去した。旧地形プレビュー専用の枠で、道路編集では使わない。
- L＋ドラッグのライトギズモをカメラの注視点中心に置き、注視点までの距離と画角から画面に収まる大きさにした。

### 2026-09-06 23:41 — 移動ギズモの修正

- カメラに向いた短い軸を一定長へ引き伸ばす処理を廃止。全軸に共通倍率を使い、不自然な向きの強調を防ぐ。
- 軸の方向と1pxあたりの移動量を投影位置での微分から計算し、近接時のプローブ点の消失と移動倍率のずれを解消する。

### 2026-09-06 16:20 — 道路マテリアル

- RoadのMaterial入力へSurfaceなどのResultを接続し、道路UVで色・法線・ラフネス・メタルネス・AOを表示できる。未接続時は単色表示。
- 道路ごとに材質を評価し、UV反復長でタイルの実寸を指定する。UVチェッカーをオフにすると通常の材質表示に戻る。
- プロジェクト形式を版9へ更新。旧RoadのPath・境界接続を維持し、Material入力を追加する。

### 2026-09-06 15:01 — 道路の1 m分割とUV表示
