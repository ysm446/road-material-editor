## 未リリース

### 2026-09-07 08:50 — 轍を車線に合わせる

- Road Mask の轍に「車線に合わせる」を追加。Road の車線数から各車線の中央に轍を置く。「両車線」は対向車線にも置くか。既存のファイルは手入力のまま読む。

### 2026-09-07 08:30 — 車線数と車線境界線（破線）

- Road に車線数（進行方向 1〜8、対向 0〜8）を追加。車線幅は全幅÷合計。対向 0 で一方通行。
- Lane Marking に車線境界線を追加。同方向の車線の間に破線（長さ・間隔、間隔 0 で実線）を引く。中央線は進行方向と対向の境に引き、矢印は各車線に置く。
- 保存はキー追加のみ（版15のまま）。

### 2026-09-07 08:00 — Shoulder の材質レイヤーと変位

- Shoulder に Road と同じ材質スロット（Material 1〜4、Mask 2〜4）、スロットごとの座標と反復長、ブレンド幅、変位量を追加。路肩も材質のハイトで押し出される。
- 路肩では Road Mask の「端の減衰」の 右＝境界側、左＝外側。既定の座標はワールド XZ。
- 保存はキー追加のみ（版15のまま）。

### 2026-09-07 07:40 — Road Mask の端の減衰に「側」を追加

- Road Mask の「端の減衰」で 両側 / 左 / 右 を選べるようにした。左右は Path の進行方向基準で、走行側には依存しない。Mask 3 を左の端、Mask 4 を右の端にすると、Road の端の層を左右で別の材質にできる。

### 2026-09-07 07:20 — Merge ノード

- Merge ノードを追加。Road・Shoulder・Decal などの RoadSurface を繋ぐと 1 つの RoadSurface にまとめ、Mesh Output 1 つで道路と路肩を同時に表示できる。入力は繋ぐたびに 1 本増える。
- 同じノード由来のメッシュは 1 回だけ積む（同じ Road を 2 つの枝から入れても道路面は二重にならない）。複数の Mesh Output にまたがる重複も除く。
- プロジェクト形式を版15へ更新。

### 2026-09-07 06:50 — Shoulder ノード（路肩の第一段）

- Shoulder ノードを追加。Path に Road の Left / Right か別の Shoulder の Outer を繋ぐと、境界の頂点を共有したまま外側へ幅と横断勾配で路肩を張る。出力は RoadSurface（Mesh Output へ）と Outer（次の路肩や Road へ）。
- 左右は Path の進行方向で決まり、走行側の設定には依存しない。
- プロジェクト形式を版14へ更新。

### 2026-09-07 06:10 — 道路メッシュの部分描画と途中経過の表示

- Lane Marking や Decal の生成が失敗しても（例: Path の点を全部消した）道路面は消えなくなった。失敗したノード名と理由をグラフパネルに出す。
- Road / Lane Marking / Decal の出力ピンをクリックすると、そのノードまでの道路メッシュをビューポートに出す。「Mesh Output へ戻す」か背景のダブルクリックで戻る。

### 2026-09-07 05:11 — 面上のパスと Decal ノード

- Path の入力を Surface（Mesh 型）に変更。Road の RoadSurface を繋ぐと面の座標で保持し、道路を変形しても追従する。路面の上で点を置き、路面に沿ってドラッグできる。
- Decal ノードを追加。面上の Path に沿って幅指定の帯を道路面と一体で貼り、材質の不透明度で模様をくり抜く。
- プロジェクト形式を版13へ更新。旧地形パスの Base への接続は読込時に外れる。

### 2026-09-07 04:42 — Surface ノードのサムネイル

- メッシュシーン表示中など合成結果が無いとき、Surface などのレイヤーノードに割り当てた材質のサムネイルを出す。

### 2026-09-07 04:34 — 道路の材質スロットと Road Mask

- Road に Material 2〜4 と Mask 2〜4 を追加。Road Mask ノード（轍 / 端の減衰 / 長さ方向ノイズ / 一様）で被覆率を決め、
  スロットの材質をハイトで競合させて混ぜる。変位もブレンド後のハイトで行う。
- スロットごとに「道路に沿う / ワールド XZ」の座標と UV 反復長を選べる。路肩や地面と地続きにする層はワールド XZ。
- プロジェクト形式を版12へ更新。

### 2026-09-07 02:59 — 白線の UV の向きと深度バイアス

- Road と Lane Marking に「UV の向き」を追加。横長の素材を道路や白線の長さ方向に沿わせられる。
- 白線の帯を深度バイアス付きで路面の後に描き、路面の分割との差で石が突き抜けて穴になる問題を直した。
- 材質に不透明度マップを付けたとき、合成が「不透明」のままなら自動で「マスク抜き」に切り替える。

### 2026-09-07 02:37 — 材質の不透明度と合成モード

- 材質に不透明度のマップと定数、合成モード（不透明 / マスク抜き / 半透明）、しきい値を追加した。
- 白線・矢印の帯は材質の合成モードに従い、剥げた塗料や薄く消えかけた塗料を表現できる。道路面は常に不透明。

### 2026-09-07 02:26 — 白線の路面追従

- 白線と矢印が道路面の変位に追従するようにした。頂点に道路 UV を持ち、路面と同じハイトで押し出す。

### 2026-09-07 02:17 — テセレーションの細かさ

- 「分割の上限」を 64 まで広げ、「分割する辺の長さ（px）」をプレビュー設定に追加した。近くは石の粒が形として出て、遠くは割らない。

### 2026-09-07 01:42 — 道路のテセレーションとワイヤーフレーム表示

- 道路メッシュにも平面と同じテセレーションを適用。プレビュー設定「道路」で有効化と分割の上限を設定する。
- Road ノードに「変位量」を追加。Material のハイトで路面を法線方向へ押し出す（既定 0）。
- 表示メニューに「ワイヤーフレーム（分割後）」を追加。シェーディングの上に分割後の辺を重ねる。

### 2026-09-07 01:29 — 走行側と進行方向の矢印

- プレビュー設定の「道路」に走行側（左側通行 / 右側通行）を追加。プロジェクトで 1 つ持ち、保存とアンドゥの対象。
- Lane Marking に進行方向の矢印を追加。左右の車線の中央に一定間隔で置き、走行側の車線は線形の向き、対向車線は逆向きにする。
- Road の Left / Right を進行方向に向かっての左右（右手系）に合わせた。以前は逆だった。バンク角の「正で Left 側上がり」もこの向きに従う。

### 2026-09-07 00:44 — 縦断曲線とバンク角

- 実寸 Path に縦断ポイント（縦断曲線長・オフセット）とバンクポイント（設計速度・自動/手動・角度）を置けるようにした。
- Road が縦断の放物線と、曲率半径と設計速度から求めた自動バンク角、手動バンク角を道路面・境界・白線へ反映する。
- プロパティの「道路線形」で編集モード・バンクの有効化・設計速度・摩擦係数・平滑化を設定する。
  ビューポートでは Ctrl＋クリックでポイントを置き、線に沿ってドラッグする。手動バンクは回転リングで角度を回す。
- プロジェクト形式を版11へ更新。

### 2026-09-07 00:20 — 白線ノード・表示メニュー・ライトギズモ

- Lane Markingノードを追加。RoadのRoadSurfaceを受け、中央線1本と左右の外側線を帯ポリゴンで生成し、道路とまとめてMesh Outputへ渡す。
- 線幅・端からの距離・浮かせ量・UV反復長を設定でき、Materialに塗料の材質を接続できる。UVは幅方向0〜1、長さ方向は実距離基準。
- プロジェクト形式を版10へ更新。旧アプリで白線ノードが読み飛ばされて道路が消えることを防ぐ。
- ビューポートの「表示 > ハイトの範囲」を撤去した。旧地形プレビュー専用の枠で、道路編集では使わない。
- L＋ドラッグのライトギズモをカメラの注視点中心に置き、注視点までの距離と画角から画面に収まる大きさにした。
