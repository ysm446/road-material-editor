# road-material-layers — 道路材質のレイヤー構造と路肩との接続

作成日時: 2026-09-07 03:40
更新日時: 2026-09-07 12:00

道路 1 本の材質をどう組み立て、路肩とどう接続し、最終的にどう書き出すかの設計。
最終出力はハイエンドのゲームグラフィックを想定する。決定の経緯は [plan](../plan/plan.md) の
「道路材質のレイヤー構造」を参照。

## 基本構造

道路 1 本 = **タイル材質（最大 4 種）＋ 道路空間のブレンドマスク ＋ 帯メッシュ**。

- **タイル材質**は既存の合成器がタイル 1 枚として作る（色 / 法線 / ラフネス・メタルネス・AO・不透明度 / ハイト）。
  Surface ノードなどの Result を Road の材質スロットへ繋ぐ。
- **道路空間マスク**は「横位置 × 実距離」で決まる、繰り返さない低解像度のテクスチャ。轍、端の汚れ、
  長さ方向のムラのように道路に沿って変わるものはここで決める。Road Mask ノードが作り、Road のマスク入力へ繋ぐ。
- **帯メッシュ**は白線・矢印・停止線。材質のレイヤーには載せない（30 m ごとの矢印のように位置が変わるものは
  タイルに載らないため）。塗料材質の不透明度と合成モードで摩耗を表す。

ユニークテクスチャを道路ごとに焼く方式は取らない。100 m の道路を 1 cm/px で焼くと 600×10000 px になり、
VRAM と管理が重い。ハイエンドでもタイル材質 ＋ マスク ＋ デカールが一般的で、必要なら最終出力の選択肢として後から足す。

## レイヤーの段

| 段 | 内容 | マスク | 出力 |
| --- | --- | --- | --- |
| 1 | 下地アスファルト | なし。タイル材質 1〜2 種を低周波ノイズで混ぜる | スロット 1 |
| 2 | 轍（磨かれた部分） | 横位置の断面プロファイル（車線中央 ± タイヤ幅）× 長さ方向ノイズ。ラフネス低め、色薄め。必要なら数 mm の凹み | マスク R → スロット 2 |
| 3 | 路肩側の汚れ・砂利 | 道路端からの距離で減衰 × ノイズ | マスク G → スロット 3 |
| 4 | ひび・補修・オイル染み | 長さ方向ノイズのしきい値。まとまった形は R4 のスプラインデカール | マスク B → スロット 4、デカール |
| 5 | 白線・矢印・停止線 | 帯メッシュ。塗料材質に摩耗マスク | 別メッシュ |
| 6 | 濡れ・水たまり | ハイトの低い所へ水位で張る（Liquid の考え方） | マスク A（後続） |

スロットは 4 つまで。それ以上は Road を区間で分けるか、マスクを 2 枚にする。

## ブレンドの規則

- マスクの R / G / B がスロット 2〜4 の被覆率。スロット 1 の重みは `1 − (R + G + B)` を 0 で切る。
- 重みだけで混ぜず、各スロットのハイトで競合させる。規則は合成器の `HeightBlendWeight` と同じで、
  境界を材質の凹凸なりにぎざぎざさせる（砂利の高い所が先に顔を出す）。境界の柔らかさは Road の「ブレンド幅」。
- 変位はブレンド後のハイト。帯メッシュの押し出しも同じブレンドを使う（`displacementSource`）。
- 法線はタンジェント空間の xy を重みで混ぜて正規化する。厳密な RNM ではないが、道路の層は高低差が小さく十分。

## テクスチャ座標

スロットごとに **道路に沿う（道路 UV）** か **ワールド XZ 平面** かを選ぶ。

| 座標 | 向く層 | 理由 |
| --- | --- | --- |
| ワールド XZ | 路肩や地面と地続きにしたい層（砂利、土、汚れ）、方向性の無い材質 | 同じ材質・同じ反復長なら継ぎ目が消える。道路の勾配・バンクは数度なので投影の伸びは 1% 未満 |
| 道路 UV | 方向性のある層（轍、摩耗、タイヤ痕）、白線 | ワールド投影だとカーブで模様が道路を横切る |

道路空間マスクと帯メッシュは常に道路空間。頂点は道路 UV（`MeshVertex::roadUv`）を持ち、ワールド投影は
シェーダで位置の XZ から作るので頂点形式は変えない。

## 路肩との接続

継ぎ目を隠すのではなく、**継ぎ目で両側が同じ値になる**ように作る。

- **ジオメトリ**: 路肩は Road の Left / Right 境界の頂点を起点にする。同じ中心線を同じ 1 m 刻みで標本化しているので
  頂点位置が一致して水密になる。共有する辺はテセレーションの分割数も同じになる（両端の点が同じため）。
  断面（幅、横断勾配 4〜6%、端の処理）は路肩ノードが持つ。折れ目は頂点共有で自然に稜線になる。
- **材質**: 道路側の「端の層」（マスク G）を境界で重み 1 にし、その材質を路肩の下地と同じ材質・同じワールド XZ 座標にする。
  境界では両側が同じ材質を同じ座標で評価するので、色・法線・ハイトが一致し、押し出しも連続する。
  変位を境界で 0 へ落とすフェザーは要らない。
- **グラデーション**: 端の層の減衰幅とノイズで決める。アスファルトの縁が崩れて砂利に混ざる表現はハイトブレンドが作る。
  路肩側にアスファルトの欠片を散らしたければ、路肩ノードにも「道路側の層」を 1 つ持たせ、境界からの距離で減衰させる。
  マスクの横軸は「道路端からの距離」で統一し、道路側と路肩側で同じ関数を使う。
- **段差のある舗装端**: 2〜3 cm の段差は材質では表せないので、路肩ノードの断面オプション（境界から数 cm の面取り列）にする。
  縁石は同じ仕組みの延長で R5 で断面を増やす。

## 面上のパスとデカール（2026-09-07）

- Path の入力ピンは Surface（Mesh 型）。Road の RoadSurface を繋ぐと、その Path は**面の座標**
  （x = 横位置 m、z = 始点からの実距離 m、y = 面からの高さ）で保持される（`PathSettings::surfaceSpace`）。
  道路の線形・幅・縦断・バンク・変位を変えても、パスは面に貼り付いたまま追従する。
  頂点の UV や三角形番号を記録する方式は再生成で破綻するので取らない。
- 繋いだ時点で世界座標の点を面の座標へ写す（`RoadSurfaceCoordinates`）。外すと数値はそのまま実寸 XYZ として扱う。
- ビューポートではカーソルのレイと道路面の交点（`RayHitsRoad`）へ点を置き、路面に沿ってドラッグする。世界軸のギズモと縦断 / バンクの編集は出さない。
- Decal ノードは RoadSurface と面上の Path と Material を受け、パスに沿った幅 widthMeters の帯を道路面と一体で
  押し出される帯メッシュとして貼る（`BuildDecal`。約 0.25 m で刻む）。UV は幅方向 0〜1、長さ方向はパスに沿った実距離÷反復長。
  材質の不透明度で模様をくり抜く。白線と同じ深度バイアスの帯パスで描く。出力の RoadSurface は Lane Marking や Mesh Output へ繋ぐ。
- 後続: 帯を道路空間マスクへスタンプする出力（材質レイヤー側で馴染ませる表現）。

## ひび割れ（Crack ノード、2026-09-07）

- Decal と同じ帯メッシュを、乱数で自動配置する。`BuildCracks(road, lanes, settings)`。同じ設定と種なら同じ結果（xorshift32）。
- 塊の数は密度（100 m あたり）× 道路長。中心の実距離は一様、横位置は一様 / 轍寄り（車線中央 ± 0.75 m）/ 端寄り（端から 0.3 m）。
- 幹は 0.4 m 刻みのランダムウォーク（向きのばらつき ± 設定値）。縦は長さ方向、横は車線を横切り、横の長さは車線幅が上限。両端は幅 30% まで細くする。
- 枝は幹の途中から 30〜70° で分かれ、長さは幹 × 比 × 0.6〜1.2、根元の幅は幹 × 比、先端で 0。半分の枝は中点から反対側へ子枝を 1 本出す（長さ半分）。
- 帯は `AppendSurfaceStrip`（道路座標の折れ線 ＋ 点ごとの幅 → 約 0.25 m 刻みの帯）。Decal もこれを使う。
- 材質は幹・枝で共通（Material 入力）。1024×128 のような横長素材は「UV の向き = U」で長さ方向に沿わせる。

## 書き出し

「メッシュ（位置・法線・接線・道路 UV）＋ タイル材質の PBR セット ＋ 道路マスク PNG」。
エンジン側では「タイル材質 4 種 ＋ RGBA のブレンドマスク ＋ 2 つ目の UV」の標準的なレイヤードマテリアルになる。
ワールド投影の層はエンジン側でも同じ投影（ワールド整列 UV）で組む前提。マスクのチャンネルの意味は固定する
（R = スロット 2、G = スロット 3、B = スロット 4、A = 予約）。

## 実装の現在地（2026-09-07）

- Road Mask ノード（`graph/RoadMask.h`）: 轍 / 端の減衰 / 長さ方向ノイズ / 一様 / ワールドノイズ、長さ方向のムラ、強さ、反転。
  ワールドノイズ（2026-09-07）はワールド XZ で評価する等方の FBM。`BakeRoadMask` に `RoadGeometry` を渡し、行の左右端からテクセルのワールド座標を補間する。
  路肩や地面と地続きの模様（砂利の溜まり、土の染み）に使う。長さ方向ノイズは道路に沿って伸びるので路肩には向かない。
  純粋関数 `EvaluateRoadMask(横位置, 実距離)` と、道路 1 本ぶんの RGBA8 画像へ焼く `BakeRoadMask`（横 256 px、1 m あたり 16 px）。
- Road: 入力 Path / Material 1〜4 / Mask 2〜4、スロットごとの座標（道路 UV / ワールド XZ）と反復長、ブレンド幅。
  スロット 2〜4 は材質とマスクの両方が繋がったときだけ有効。`CompileMeshGraph` が `SceneMesh::layerStacks` と `roadMask` を作る。
- 混ぜ方（2026-09-07）: スロット 2〜4 に「マスクどおり / ハイトで競合」。**マスクどおり**が既定で、被覆率がそのまま重み。
  境界は「下地とのハイト差 × ブレンド幅」だけ崩す（`LayerHeightBlend` の maskWeights）。マスクどおりのスロットが先に取り、残りを下地とハイト競合のスロットで分ける。
  **ハイトで競合**は従来の「ハイト ＋ 被覆率」の競争で、砂利の粒だけ顔を出す表現向け。旧ファイルは競合で読む。
- Surface などのレイヤーノードの Mask 入力は旧地形の合成用（タイル UV）で、道路の配置には使えない。繋がっていないときはピンを出さず、
  プロパティのマスク節も設定済みのときだけ出す。道路の上の配置は Road Mask（道路座標 / ワールド XZ）一本にする。
- 下地のハイトで絞る（2026-09-07）: スロット 2〜4 に「使わない / 下地の高い所 / 下地の低い所」としきい値・柔らかさ。
  `ApplyHeightGate` が下地（スロット 1）のハイトを読んで被覆率に掛け、下地の重みを残りで埋め直す。ピクセルと変位（`BlendedHeightLevel`）の両方で同じ計算。
  Road Mask が「だいたいこの辺」（轍・端・ノイズ）、下地の凹凸が「その中のどこ」（砂利の粒の間に土が溜まる）を決める分担。
  既存のハイトブレンド（`LayerHeightBlend`）は境界の形を決める役のまま。
- 描画: `MeshPbr.hlsl` の `LayerCoverage` / `LayerHeightBlend` / `BlendedHeightLevel`。ピクセルはスロットごとに色・法線・Surface を
  引いてハイトで競合させ、頂点 / ドメインはブレンド後のハイトで押し出す。白線は押し出し元の道路のレイヤー定数を写して同じハイトを読む。
- 保存形式は版12。確認画像は `data/road-profile-check/layers.png`（端の砂利をワールド XZ、轍を道路 UV）。
- Shoulder ノード（第一段、2026-09-07）: 入力 Path（Road の Left / Right か Shoulder の Outer）と Material、出力 RoadSurface と Outer。
  `BuildShoulder` は境界の列をそのまま列 0 に写し、隣の列から外向きを決めて幅ぶん押し出す（横断勾配は % で外側へ下がる）。
  頂点を共有するので水密。列の向きは左右で逆になるので三角形ごとに法線が上を向くよう並べる。走行側には依存しない。
  Road は Shoulder の Outer からも作れる。
- Shoulder の材質（第二段、2026-09-07）: Road と同じレイヤー構造（Material 1〜4、Mask 2〜4、スロットごとの座標と反復長、ブレンド幅、変位）。
  `AttachRoadLayers` をそのまま使う。路肩の横位置は境界（列 0）が Right、外側（Outer）が Left なので、Road Mask の「端の減衰」で
  「右」を選ぶと境界側の層、「左」を選ぶと外側の層になる。既定の座標はワールド XZ（道路の端の層と地続きにするため）。
  境界で段を出さないには、道路の端の層と路肩の下地を同じ材質・ワールド XZ・同じ変位量にする。
- 舗装端の段差（2026-09-07）: `stepHeightMeters` > 0 のとき、境界（列 0）の直後に横幅 `stepWidthMeters` の面取り列を 1 つ挟み、
  その列から外側の全列を段差ぶん下げる。境界の頂点は共有のまま（水密）。列は「0、面取り、以後約 1 m 刻み」で、段差 0 なら面取り列は無い。
  縁石は同じ仕組みの延長で R5 に断面を増やす。

## 実装順

1. Road Mask ノードと道路空間マスクの評価（轍 / 端の減衰 / 長さ方向ノイズ / 定数、長さ方向のムラ、反転）。
2. Road の材質スロット化（4 スロット ＋ マスク入力 3 本）とブレンド描画、ブレンド後のハイトによる変位。
3. スロットごとのテクスチャ座標（道路 UV / ワールド XZ）と反復長。
4. 路肩ノード（境界の頂点共有、断面、端の層）。頂点共有・幅・横断勾配・Outer・材質レイヤー・段差の面取り列まで実装済み。
5. R4 のスプラインデカール、書き出し。
