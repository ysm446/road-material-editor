# 境界マテリアル

作成日時: 2026-09-08 01:44
更新日時: 2026-09-08 02:23

## 用途と操作

路面・沿道のレイヤーマテリアルはそのまま使い、境目の形だけを画像で指定する。境界アセットは左右や別の道路で共用できる。

1. テクスチャ一覧へ境界マスクとハイト画像を読み込む。
2. 「境界マテリアル」タブの空白を右クリックし「新規作成」。既存アセットはダブルクリックで編集。
3. 境界マスク・ハイトを選択し、境界幅と道路に沿う繰り返し長をメートルで指定する。
4. Roadで左右の沿道と「編集する区間」を選び、「沿道の材質と形状」で境界マテリアルまたは「なし」を選ぶ。区間を分割して割り当てを変え、「切替位置」「移行距離」で調整する。「材質をなじませる」をオンにする。形状にも溝を反映するには「凹凸をなじませる」とプレビューのテセレーション・変位を有効にする。

マスクはRチャンネルをリニアで読み、白が路面・黒が沿道。「マスクを反転」で逆にできる。Uは道路から沿道へ横切る向き、Vは道路に沿う向き。画像がU方向につながる場合は反復方向をUへ切り替える。反対側への配置時は座標の向きを自動で揃える。

ハイトはRチャンネル、既定基準0.5。変位量は `(height - heightCenter) * 2 * depthMeters`。基準0.5のとき黒0は指定深さだけ下がる。白1は同じ量だけ上がる。画像の平坦部に合わせて基準を設定する。境界帯の外端では変位を減衰させる。

## 描画

境界帯の幅は道路・沿道の寸法に収まるよう制限する。材質の分布は既存の道路空間マスクへ境界画像を合成し、帯の外側では既存の接続へ戻す。道路の進行方向の材質切替も維持する。

沿道の内端がBlendで輪郭固定でない区間にだけ適用する。幅8の制御画像の列ごとに境界アセットを割り当て、区間の適用率と沿道の素材比率を書く。左右同時接続ではRGBAへまとめる。各側8種類まで、同一アセットの再利用は種類を増やさない。異なる境界のマスクは重み付き和で混ぜ、順序による偏りを避ける。ハイトも区間の重み付き和で混ぜ、「なし」へは徐々に減衰する。UVは道路全体の実距離を基準とし、分割位置でリセットしない。段差保持・固定区間に移るところは区間の混合率で効果を減らす。道路と沿道の両面が同一制御画像と境界UVを参照する。

境界ハイトを既存の変位へ加算し、ピクセル側ではハイトの差分から法線を求め、既存法線にRNMで合成する。追加のノーマル画像は第一段では入力しない。制御画像のアップロード・状態遷移・遅延破棄は既存の道路マスクと同じ経路を使う。

## 保存と互換

プロジェクト版23、配置節版6。`SurfaceLayoutDocument.boundaryMaterials` に安定ID、名前、テクスチャID、幅、反復長、深さ、基準値、軸と反転を保存する。沿道の `SurfaceSpan.boundaryMaterial` は0なら未指定。道路本体の帯への割当は拒否する。旧配置節1〜4は未指定、版5の帯全体の割当は各区間へコピーして読み込む。TextureLibraryの実行時IDは保存時にファイル内IDへ変換し、読込時に戻す。Undoスナップショットもアセットと割当を保持する。

参照中のアセットの削除は拒否する。画像の削除確認には境界アセットの使用箇所を表示し、実際に削除した際は参照を解除する。画像ファイルが見つからない場合は既存のリンク切れテクスチャとして参照を保持する。

## 検証と制約

- CPUテスト: 保存往復、寸法・必須項目・ID重複・参照切れの拒否、共有アセットのUndo/Redo、左右の座標方向、両面の制御一致、歩道への適用抑制。
- HLSL: PS/DSをDXCでコンパイル。アプリ起動時に使用エントリもコンパイル。
- Release試用: `data/boundary-material-test.tgproj`。先に生成した画像を割当済み。`data/boundary-close.tgproj` は材質の色を単純化した近接確認用。画像・プロジェクトは手元の `data/` に置きコミットしない。
- 区間は沿道の区間と共通。境界だけの独立した区間列、専用3Dプレビュー、独立したノーマル入力は後続。片側8種類を超える割当はエラーにして文書変更を適用しない。
- 溝の形状精度はテセレーション密度に依存する。細い溝では密度を上げて確認する。生成画像の反復端は完全一致しておらず、素材側の端補正は未実施。画像の平坦部の濃淡も試作品のまま。
