# 独立したレイヤーマテリアル

作成日時: 2026-09-08 00:41
更新日時: 2026-09-08 00:41

## 操作

- レイヤーマテリアル一覧の右クリックから新規作成・編集・削除。ダブルクリックで編集画面を開く。
- Roadの路面・沿道の「材質」から同じアセットを選択できる。材質を変更しても幅・高さ・役割・境界条件は保持する。
- 「材質を編集」は使用中の全区間へ反映。「複製して編集」は材質を新規IDで複製し、選択区間の参照だけを変更する。
- 沿道の幅・高さはRoad側で編集する。共有していた形状は必要時に複製し、他区間への変更を防ぐ。使用中の材質は削除できない。
- 通常素材のサムネールは球、合成材質は正方形の平面。幅・高さ・切替位置の編集は材質サムネールの再生成条件に含めない。

## 所有権と保存

`SurfaceLayoutDocument.layerMaterials` が名前・最大4層・任意の材質グラフ・合成幅・変位量を所有する。`SurfacePreset` は役割・断面・境界・公開値定義と `layerMaterial` IDを持つ。区間は形状プリセットを参照する。材質IDも文書内の共通ID空間に属する。

プロジェクト版21、配置節版4を保存する。`layerMaterials` にだけ材質内容を書き、`presets` には `layerMaterial` 参照を書き出す。素材アセット参照は従来同様に保存ID／実行時ID間で付け替える。未使用の材質も保存対象とする。

旧配置節1〜3は読み込み可能。プロジェクト読込時に各旧プリセットから材質を新規IDで取り出し、形状・配置・材質内容を保持する。同じ見た目でも旧プリセット間の材質は自動統合しない。利用者が同じ材質を割り当てた時点で共有する。移行は繰り返してもIDを増やさない。

既存評価器との互換のため、`SurfacePreset` に旧材質フィールドを残す。編集文書ではリンク済みの埋込値を空にし、`ResolveLayerMaterials` で評価用の一時コピーへ展開する。保存とアプリ編集の正本は独立材質であり、二つの材質設定を編集する仕様ではない。版4の形状に埋込材質が混在する入力は拒否する。

## 検証と残る範囲

CPUテストで旧形式移行、共有材質の伝播、段差保持、独立複製、保存往復、Undo/Redo、重複ID・参照切れ・ID枯渇時の非破壊失敗を確認する。Releaseで旧プロジェクトから版21へ保存、再読込後の配置JSON一致、サムネールと材質編集の平面プレビューを確認した。

評価器の上限は引き続き路面3構成・横接続時の左右各2構成。形状が異なる場合は同じ材質IDでも別構成として数える。任意の形状数を同じ材質数へ集約する最適化は今回の範囲外。路肩／歩道の役割は既存配置と作成時の選択で保持し、区間単位で役割を切り替えるUIは後続とする。
