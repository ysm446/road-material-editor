# 道路本体の区間材質 — 試用手順

作成日時: 2026-09-07 17:28
更新日時: 2026-09-07 17:45

## 試せること

通常起動で、Roadの材質をプリセット化し、区間へ割り当てて切り替えられる。
道路全長0.1〜50 m、同時に使うプリセットは1本につき最大3種類、各プリセット最大4層。
既存のPath → Road → Mesh Outputを使う。道路そのものを分割する必要はない。

## 操作

1. プロジェクトを開き、グラフのRoadノードを選ぶ。
2. プロパティ上部の「路面区間」で「区間編集を始める」を押す。現在のRoadの4材質スロット、UV、マスク、混ぜ方、高さ条件をプリセットへ取り込む。
3. 「分割」で選択区間を中央から二つに分ける。「区間」で編集する側を選ぶ。
4. 「プリセット」で既存の材質を割り当てる。別の材質を作る場合は「複製して編集」を押し、「素材」を変更する。
5. 「終点」で次の区間との境界を動かす。「始端の移行」「終端の移行」を増やすと材質が緩やかに変わる。
6. 必要なら「プリセットの材質」で名前・凹凸の高さ・編集する層・素材・反復長を調整する。上層は「層を使用」で有効にし、マスクと強さを選べる。
7. 通常の保存で記録し、Ctrl+Z / Ctrl+Yで変更を戻す・やり直す。

同じプリセットの編集は、それを使う全区間へ反映される。特定の区間だけ変えたいときは先に複製する。
数値はCtrl+クリックで直接入力し、Enterで確定できる。グラフとプロパティの境界を上へ動かすと編集欄を広く使える。

「削除」は隣の区間を広げて埋める。最後の区間は削除できない。
「区間編集を解除」はRoadの元の材質へ戻す。沿道の記述とプリセットは残る。解除・再開もUndo対象。
Pathの長さを変更した場合は「道路長に合わせる」で区間の比率を保って伸縮する。
範囲が合わない間は元のRoadを表示し、理由をプロパティへ表示する。

## プリセット内部の詳細設定

「編集する層」で下地または上層を選び、座標（面に沿う／ワールド XZ）と反復長を設定する。
上層は「層を使用」を有効にすると、混ぜ方、下地の高さ条件、マスクの詳細を編集できる。
轍はタイヤ間隔と帯幅、道路端は左右と幅、ノイズは大きさとしきい値を調整する。
ムラ・シード・反転もRoad Maskノードと同じ設定。ブレンド幅はプリセット内の全層で共有する。
素材未指定時は色・粗さ・金属度・AOを使う。項目が収まらない場合はプロパティ内をスクロールする。

RoadのMaterial／Mask入力は、開始時の取込元と解除後の表示用として残している。
区間編集中はプリセット側が描画に使われ、元の入力側への変更は反映されない。
今後は既存データの移行を整え、Roadを形状・車線、プリセットを材質・マスクの担当へ整理する。

## 表示と保存

通常のMesh Outputと途中ノードのプレビューへ反映する。白線・Decal・Crackは自分の材質を使い、変位だけ配置後の道路材質から読む。
道路の形状と区間の割当は別々に保存する。材質の評価専用データはメッシュ数へ数えない。
保存形式は版18。版17の単層記述も移行できる。実装の詳細は [配置記述](surface-layout-data.md)。

## 現段階の制限

- 道路本体の区間材質を試すUI。沿道の配置、歩道・縁石の断面、自動で高低差を吸収する接続は未実装。
- 公開値の「荒れ具合」の始終端を結線する機能は後続。今はプリセット内のマスクの強さを調整する。
- プリセットは既存の道路材質から作る。専用ノードグラフやプリセット専用アセット一覧は後続。
- UIが作る区間列は道路全長を隙間なく覆う。外部で作った空白や範囲外の配置はそのまま表示できない。
- 取込は各材質スロット1層・全チャンネルに対応。未対応の構成は理由を表示して拒否する。
- 境界の移行は各区間長の半分までに抑える。道路長変更時の全自動追従、曲線や全視点での継ぎ目検証は後続。
