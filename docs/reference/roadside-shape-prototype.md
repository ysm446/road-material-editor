# 沿道形状の試作

作成日時: 2026-09-07 18:04
更新日時: 2026-09-07 22:25

## 操作

Roadを選び、プロパティ先頭の「沿道の配置」で左沿道・右沿道を選ぶ。
未作成の側は「作る沿道」で路肩・歩道を選び、「全長に作成」で1区間を作る。仮路肩は幅2 m・外端 −6 cm、仮歩道は幅2 m・高さ15 cm。
既存の同側の帯は上書きしない。道路本体の区間編集とは独立して作成できる。
「編集する区間」で対象を選び、「切替位置」と「移行距離」で次の区間との境界を調整する。
「沿道区間を分割」は中央で分割し、「沿道区間を削除」は隣接区間で範囲を埋める。最後の1区間は削除できない。
異なるプリセット間に移行距離がない場合は自動で補う。道路長と異なる場合は「道路長に合わせる」で区間割合と移行距離を比例伸縮する。
パス編集時は路面・左右沿道の区間割合と移行距離を自動で道路長へ合わせ、パス変更と同じUndoへ保存する。道路が一時的に無効な場合や0.1〜50 mの試作範囲外では追従を保留する。
これらも保存・Undoの対象。区間数と使用プリセット数は別で、横接続は沿道各2種類まで。
作成と距離の変更は保存・Undoの対象。表示は「形状を表示」で切り替え、状態はプロジェクトに保存される。旧ファイルで設定がない場合はオフになる。
保存済み沿道はオンにすると形状と下地材質を再生成する。

対象区間を選んだ後、「沿道プリセット」でプリセットを割り当てる。「プリセットを編集」で専用画面へ移り、名前・共有寸法・最大4層の素材・反復長・座標・マスク・ハイト合成を設定する。
素材なしの場合は色と粗さを編集できる。同じプリセットを使う沿道区間へ共通で反映する。
材質は断面と同じ区間の混合率で切り替わる。断面の垂直部分も実距離のUVに含む。

## この段階で扱うもの

左右各1帯、道路全長0.1〜50 mを覆う配置。道路格子の左右端を基準に断面を置く。
幅方向は道路の横断方向、高さは世界のY方向を基準とする。
異なる点数の断面を断面長の比率で対応付け、道路の進行方向へ滑らかに補間する。
断面の稜線で法線を分け、隣り合う面は同じ位置標本を参照する。
仮形状はデータから生成し、外部のメッシュ素材を必要としない。

## 沿道の格子分割

プリセットから生成する路肩・歩道は、幅方向と進行方向のセル辺が1 m以下になるよう自動分割する。道路端、断面の角、区間境界と移行端を保持するため、完全な等間隔の正方形ではなく、境界付近には小さいセルができる。三角形の対角線はこの1 m上限の対象外。分割幅の編集UIは設けず、基準値は1 mとする。

幅方向は全プリセットの断面点を共通の断面長比へ集め、各断面の幅と高さの差を使って区間を細分化する。進行方向は道路の行と沿道区間の境界を基準とし、生成した位置で1 mを超える辺があれば距離の中点に行を追加して再評価する。カーブ外側、縦断勾配、断面の移行による辺の伸びにも対応する。歩道の角では従来どおり法線を分ける。

生成量は断面256列、進行方向8192行、位置標本262144点を上限として制限する。テセレーションの前段となるベースメッシュを変更し、シェーダの分割処理は変更しない。

Debug / Releaseのビルドと全CPUテストが成功。左右の沿道、曲がりと縦断勾配、幅9.5 mの沿道でセル辺の長さを検査し、道路端・段差・移行形状の既存テストも成功。Releaseの描画画像 `data/connection-prototype/roadside-grid.png` を目視し、路肩・歩道と材質接続を確認した。

## 制限

沿道材質は最大3プリセットの最大4層に対応。上層のマスク・ハイト競合・下地条件を専用画面で編集できる。
法線は既存のRNM合成を通す。独立表示ではハイト変位を0で評価する。
横方向の材質は「材質をなじませる」で限定的に確認できる。「凹凸をなじませる」では境界の凹凸を0へ戻して高さを接続する。[対応範囲](lateral-material-connection.md)。
境界契約の自動解決、複数帯の積み上げ、進行方向の段差端面と外周の蓋、急カーブでの自己交差検査も後続。
内端が(0, 0)でない断面、空白区間、移行距離ゼロでの異種プリセット切替は理由を表示して拒否する。
単純断面の幅・高さ・プリセット割当・複製の編集UIは対応済み。任意の断面点の編集と道路長変更への沿道の追従操作は後続。
既存Shoulderと同じ側へ置くと重なるため、試作用のRoadで確認する。
