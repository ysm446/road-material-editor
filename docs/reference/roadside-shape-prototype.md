# 沿道形状の試作

作成日時: 2026-09-07 18:04
更新日時: 2026-09-07 18:40

## 操作

Roadを選び、プロパティ先頭の「沿道形状（試作）」で左・右を選ぶ。
「路肩→歩道を作る」で、幅2 mの仮路肩（外端 −6 cm）から仮歩道（高さ15 cm）へ移る2区間を作る。
既存の同側の帯は上書きしない。道路本体の区間編集とは独立して作成できる。
「切替位置」と「移行距離」で境界とその前後の長さを調整できる（2区間の帯に対応）。
作成と距離の変更は保存・Undoの対象。表示は「形状を表示」で切り替え、再起動後はオフになる。
保存済み沿道はオンにすると形状と下地材質を再生成する。

「沿道の下地材質」で編集する区間を選び、素材・反復長・座標を設定する。
素材なしの場合は色と粗さを編集できる。同じプリセットを使う沿道区間へ共通で反映する。
材質は断面と同じ区間の混合率で切り替わる。断面の垂直部分も実距離のUVに含む。

## この段階で扱うもの

左右各1帯、道路全長0.1〜50 mを覆う配置。道路格子の左右端を基準に断面を置く。
幅方向は道路の横断方向、高さは世界のY方向を基準とする。
異なる点数の断面を断面長の比率で対応付け、道路の進行方向へ滑らかに補間する。
断面の稜線で法線を分け、隣り合う面は同じ位置標本を参照する。
仮形状はデータから生成し、外部のメッシュ素材を必要としない。

## 制限

沿道材質は最大3プリセットの下地1層に対応。上層マスクがある配置は理由を表示して拒否する。
法線は既存のRNM合成を通す。独立表示ではハイト変位を0で評価する。
横方向の材質は「横接続を試す」で限定的に確認できる。「変位もつなぐ」では境界の凹凸を0へ戻して高さを接続する。[対応範囲](lateral-material-connection.md)。
境界契約の自動解決、複数帯の積み上げ、進行方向の段差端面と外周の蓋、急カーブでの自己交差検査も後続。
内端が(0, 0)でない断面、空白区間、移行距離ゼロでの異種プリセット切替は理由を表示して拒否する。
幅・高さ・断面点・プリセット割当・複製の編集UIと、道路長変更への沿道の追従操作は後続。
既存Shoulderと同じ側へ置くと重なるため、試作用のRoadで確認する。

## 検証

Debug / ReleaseビルドとCPUテスト成功。左右、道路端の一致、移行途中の高さ、曲がりと縦断高さを持つ格子、
保存記述からの再生成、不正な入力時の出力保持を確認した。
Releaseの作成ボタンへ実クリックを入力し、2区間・2プリセット・Undo1段を確認。
俯瞰と低い視点のUI画像を目視。切替位置・移行距離のスライダー操作、曲線の描画は今回未検証。
画像とログは `data/connection-prototype/roadside-shape-*.png` / `*.log`。

下地材質の追加後もDebug / Releaseのビルド・全テストを実施。PBR定数・素材参照・UV・混合率・法線マップの左右の向きを検証。
Release画像で実素材の砂利から定数材質の歩道への移行を確認。材質編集欄は表示確認までで、素材選択のマウス操作は未検証。
材質の検証資料は `data/connection-prototype/roadside-material-*.png` / `*.log`。

沿道材質を含む既存の確認用プロジェクトをReleaseで保存→再読込→再保存し、JSON全体の一致を確認した。
