# 沿道形状の試作

作成日時: 2026-09-07 18:04
更新日時: 2026-09-07 18:04

## 操作

Roadを選び、プロパティ先頭の「沿道形状（試作）」で左・右を選ぶ。
「路肩→歩道を作る」で、幅2 mの仮路肩（外端 −6 cm）から仮歩道（高さ15 cm）へ移る2区間を作る。
既存の同側の帯は上書きしない。道路本体の区間編集とは独立して作成できる。
「切替位置」と「移行距離」で境界とその前後の長さを調整できる（2区間の帯に対応）。
作成と距離の変更は保存・Undoの対象。表示は「形状を表示」で切り替え、再起動後はオフになる。
保存済み沿道はオンにすると再生成する。

## この段階で扱うもの

左右各1帯、道路全長0.1〜50 mを覆う配置。道路格子の左右端を基準に断面を置く。
幅方向は道路の横断方向、高さは世界のY方向を基準とする。
異なる点数の断面を断面長の比率で対応付け、道路の進行方向へ滑らかに補間する。
断面の稜線で法線を分け、隣り合う面は同じ位置標本を参照する。
仮形状はデータから生成し、外部のメッシュ素材を必要としない。

## 制限

これは単色の形状プレビュー。プリセットの材質・マスク・ハイト変位は沿道へ未適用。
道路自体の材質変位による高さとの一致や、横方向の材質の馴染ませは未実装。
境界契約の自動解決、複数帯の積み上げ、進行方向の段差端面と外周の蓋、急カーブでの自己交差検査も後続。
内端が(0, 0)でない断面、空白区間、移行距離ゼロでの異種プリセット切替は理由を表示して拒否する。
幅・高さ・断面点・プリセット割当の編集UIと、道路長変更への沿道の追従操作は後続。
既存Shoulderと同じ側へ置くと重なるため、試作用のRoadで確認する。
