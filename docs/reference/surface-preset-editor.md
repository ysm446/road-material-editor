# プリセット編集

作成日時: 2026-09-07 20:33
更新日時: 2026-09-07 22:17

## 操作

Roadの配置画面で区間とプリセットを選び、「プリセットを編集」で専用画面へ移る。右カラムの画面が切り替わり、ビューポートと素材の帯は残る。「配置へ戻る」で道路の編集へ戻る。

編集は同じプリセットを使うすべての区間へ反映する。選択区間だけ構成を変えたい場合は、配置側で「複製して編集」を選ぶ。名前・共有寸法・材質の変更、ノード追加・結線・削除・移動は保存・Undoの対象。画面の切替は対象外。

上側が材質グラフ、下側が選択ノードの設定。下地を含む最大4層。「層を追加」で素材・マスク・合成を作り、現在の出力へ自動接続する。個別の「素材を追加」「マスクを追加」「合成を追加」でも組める。

丸をドラッグして出力から入力へ接続する。合成ノードの下地へ素材または直前の合成、上層素材へ素材、マスクへマスクを接続し、最後の合成を出力の面入力へ繋ぐ。同じ素材・マスクを複数の合成で共有できる。入力の接続は差し替え可能。「選択を削除」またはDeleteでノードを削除、リンクを選択してDeleteで切断する。出力ノードは削除不可。ホイールで拡縮、中ボタンドラッグでパン、「全体を表示」で収める。

素材ノードでは素材・UV・定数色、マスクノードでは「形」と被覆、合成ノードでは「混ぜ方」「下地のハイト」を調整する。「ハイトで競合」は素材の高い部分を優先し、「下地のハイト」は下の凹凸に応じて被覆を絞る。「ブレンド幅」はプリセット全層共通のハイト合成の柔らかさ。

沿道の凹凸を実際に変位させる場合は、配置画面で「凹凸をなじませる」をオンにする。独立した形状表示では材質を合成するが変位はしない。歩道の断面段差は変位モードと独立して生成する。

## 現在の範囲

保存は版19。旧版の層構成は最初の編集で同じ評価結果のグラフへ変換し、保存する。開くだけではUndo・文書変更を発生させない。沿道のマスク座標は内端から外端への断面長と道路の進行距離。ワールドノイズは曲線・段差の断面位置から世界XZを求める。轍の車線自動配置は沿道では手動オフセットに落ちる。

横接続は道路最大3プリセット・左右各2プリセット、各プリセット最大4層。独立沿道表示は各3プリセット。層数とプリセット数の制限は別である。

ノードの配置・結線は自由に編集できるが、合成結果は既存の4層評価へ展開する。合成済みの面同士を上層として重ねる処理、マスク演算ノード、公開パラメータの結線、区間ごとの寸法上書きは未実装。合成の柔らかさはプリセット共通。「出力」の未接続は定数材質、合成の上層・マスクの未接続は下地を通すため、編集途中でも保存できる。

CPUで旧4層の設定一致、道路・沿道のマスク評価一致、循環・型不一致・5層目の拒否、保存往復・破損読込の非破壊性・Undo/Redoを検証。Releaseで層追加・結線差し替え・ノード移動をドラッグし、それぞれ保存とUndo1段を確認した。

開発用の撮影は `--edit-preset <id>` で保存済みプリセットを開ける。画面・レイヤー選択は保存データに含めない。

Debugで保存済み4層グラフを再読込し、GPU検証の警告・エラーなしで描画完了。再保存した `surfaceLayouts` が元のJSONと一致することを確認した。Releaseの最終UIを撮影・目視確認し、接続済みノード削除と関連リンクの解除・保存も確認。実機でのUndo/Redoキー操作、マスクの共有編集全組合せ、大量プリセットでの負荷比較は未検証。

素材ノードには64px、素材選択欄には40pxのライブラリのサムネールを表示する。プルダウン候補の画像も40pxで、画像または名前をクリックして選ぶ。DPIに応じて拡大する。未指定・生成待ちは枠のみ表示する。

Roadの「形状を表示」「材質をなじませる」「凹凸をなじませる」はプロジェクト共通のプレビュー設定として保存する。旧ファイルにキーがない場合はオフで開くため、一度設定して保存する。
