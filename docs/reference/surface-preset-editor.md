# プリセット編集

作成日時: 2026-09-07 20:33
更新日時: 2026-09-07 20:33

## 操作

Roadの配置画面で区間とプリセットを選び、「プリセットを編集」で専用画面へ移る。右カラムの画面が切り替わり、ビューポートと素材の帯は残る。「配置へ戻る」で道路の編集へ戻る。

編集は同じプリセットを使うすべての区間へ反映する。選択区間だけ構成を変えたい場合は、配置側で「複製して編集」を選ぶ。名前・共有寸法・材質の変更、レイヤー追加と削除は保存・Undoの対象。画面の切替は対象外。

下地を含む最大4層。上層を追加して素材を割り当て、「層を使用」「形」「混ぜ方」「下地のハイト」を調整する。「ハイトで競合」は素材の高い部分を優先し、「下地のハイト」は下の凹凸に応じて被覆を絞る。「ブレンド幅」はプリセット全層共通のハイト合成の柔らかさ。

沿道の凹凸を実際に変位させる場合は、配置画面で「変位もつなぐ」をオンにする。独立した形状表示では材質を合成するが変位はしない。歩道の断面段差は変位モードと独立して生成する。

## 現在の範囲

配置・プリセットは既存の版18形式を使用する。沿道のマスク座標は内端から外端への断面長と道路の進行距離。ワールドノイズは曲線・段差の断面位置から世界XZを求める。轍の車線自動配置は沿道では手動オフセットに落ちる。

横接続は道路最大3プリセット・左右各2プリセット、各プリセット最大4層。独立沿道表示は各3プリセット。層数とプリセット数の制限は別である。

今回は順序付きレイヤーの専用編集画面を実装した。自由なノード接続、公開パラメータの結線、区間ごとの寸法上書きは未実装。これらを専用画面へ追加し、配置画面に詳細設定を戻さない方針。

開発用の撮影は `--edit-preset <id>` で保存済みプリセットを開ける。画面・レイヤー選択は保存データに含めない。
